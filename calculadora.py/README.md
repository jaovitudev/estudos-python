# 🧮 Calculadora Python

> ➕ **Resolva operações básicas com uma ferramenta leve, direto no terminal.**

Mini projeto para praticar entradas de dados, funções e estruturas condicionais em Python.

## ✨ Operações disponíveis

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão, com tratamento para divisão por zero
- ⚠️ Validação de operador

## 🧰 Requisitos

- Python 3
- Nenhuma dependência externa

## ▶️ Como executar

```bash
python calculadora.py
```

Informe o primeiro número, o operador (`+`, `-`, `*` ou `/`) e o segundo número.
