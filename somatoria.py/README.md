# 📊 Média Escolar em Python

> 🎓 **Acompanhe as notas do ano e descubra a média final do aluno.**

Notebook desenvolvido para praticar funções, entrada de dados, validação de notas e cálculos em Python.

## ✨ Funcionalidades

- 👤 Solicita o nome do aluno.
- 📝 Recebe três notas por bimestre e valida valores entre 0 e 10.
- 📈 Calcula as médias dos quatro bimestres e a média anual.
- ✅ Informa se o aluno foi aprovado ou reprovado, considerando média final igual ou superior a 5.

## 🧰 Requisitos

- Python 3
- Jupyter Notebook ou JupyterLab

## ▶️ Como executar

Na pasta do projeto, abra o notebook:

```bash
jupyter notebook media.ipynb
```

Execute as células e informe o nome e as notas solicitadas.
